## 2026-10-09：浏览器视频链接与详情接口错误

- `/jingxuan?modal_id=作品编号` 已支持提取作品编号，与分享短链接共用详情接口。给定的长短链接均指向 `7679721287379341747`。
- 实测 403 响应为 `Blocked by ArgusSecurityPlugin Uifid Not Found`。仅加 UIFID 头后变为 `Signature Not Found`；补充 UIFID 与 SecSDK 签名后，同一 Cookie 的详情请求恢复 HTTP 200 和完整作品数据。
- Web API 共用请求层增加 UIFID、同源 `s_v_web_id` 指纹与 `x-secsdk-web-signature`；不向视频下载 CDN 发送这些身份头，也不记录完整签名 URL 或凭据。签名规则核对来源：[WebSign 实现与实测说明](https://github.com/Evil0ctal/Douyin_TikTok_Download_API/blob/main/src/dtk/signing/native/websign.py)。
- 明确的 Argus 身份拒绝立即提示；其他临时 403 最多请求三次，每次生成新签名，两次等待分别为 0.5 秒和 1 秒。不误报为链接错误或作品已删除。
- 登录页按钮改为“检查登录信息”，说明它只检查本地 Cookie 的存在及保存有效期，不声称联网验证了账号或视频接口。

## 2026-10-09：客户端授权展示（已实现）

- 日常客户端界面不展示授权入口、收费信息或试用倒计时，让用户先正常体验。
- 后台保留设备登记、试用期限和授权校验；隐藏界面不等于移除授权检查。
- 体验期结束后，用户再次执行需要授权的操作时，弹出授权窗口；不要仅因启动软件就弹出购买窗口。
- 到期提示、套餐选择和扫码付款合并为一个窗口。套餐每行最多三档并排显示及“立即支付”，名称和价格从服务端读取；下单后原地显示所选套餐、金额及微信二维码。错误和付款结果均在同一窗口提示。
- 已付款且授权有效时正常使用；授权到期后再次操作时进入同一流程。
- 网络异常和设备禁用继续分别提示，不误判为体验期结束，也不引导重复付款。
- 标题仅显示“青柠视频下载”，左侧菜单为下载、登录、设置和说明。说明页读取 `core/update_checker.py` 的 `APP_VERSION` 显示版本号，另显示作者微信 `z851968` 和教程按钮，在默认浏览器打开指定飞书教程链接。
- 确认付费授权有效后显示成功状态，并在自动继续前再次在线校验，然后关闭窗口、继续原下载操作；关闭弹窗不启动下载。窗口提供刷新状态、作者微信提示和更换套餐；两个阶段均去掉复制设备编号按钮。关闭或更换套餐不会撤销服务器订单。已检测到付款但授权未确认时不能再次下单。
- 本次只修改客户端源码，通过 `python main.py` 测试，不生成客户端程序包或压缩包。

## 2026-10-08：电脑用户记录与简单统计（本地已实现，待部署）

- 固定电脑 UUID，共用于支付授权和统计。Windows 优先 SMBIOS UUID，备用 MachineGuid；固定命名空间 UUIDv5，不采集网卡信息，原始硬件值不发送到服务器。
- 标识来源、令牌与下载待上报队列保存至 Windows 用户目录。删除软件目录后仍沿用身份；全部凭据丢失时联系客服恢复，不自动发放第二次试用。备用 MachineGuid 不承诺重装 Windows 后保持不变。
- 使用 `users` 用户表和 `orders` 订单表，用户业务字段为 ID、UUID、首次联网登记时间、最近打开时间、成功下载视频总数及到期时间。旧表改名并按需补齐两列，移除下载上报去重表。迁移可重复执行，保留现有订单、下载总数和授权，迁移前自动备份 SQLite。
- 旧随机 UUID 凭有效令牌关联到电脑 UUID，保留原 ID、首次登记、付费及待支付订单、到期时间。冲突时不自动合并。首次升级保留原软件目录旧凭据，成功启动后可迁移软件目录。
- 独立启动接口更新最近打开时间，授权查询、下载上报与付款轮询不增加活跃。未知历史最近打开时间留空，尚无下载总数的旧记录从 0 起计，已有累计数量保留。
- 每个成功保存的视频记一次增量，失败、音频和图文不计；重复下载成功再次计数。后台持久化队列重试，服务器收到有效增量直接累加。按用户要求去掉去重表，接受少量网络重试导致的重复计数。
- 无需登录的 `/stats` 和 `/api/pc/stats` 只展示四项汇总：今日活跃、近 7 天活跃、近 30 天活跃、累计用户数。按北京时间今天及前 6／29 个自然日计算，页面提供刷新按钮。
- 当前只通过最近打开时间计算截至现在的活跃范围，不增加历史每日统计表、账号、管理列表或恢复码。
- 本次不清空测试记录、订单或调整测试价格；部署包不包含服务器套餐配置。客户端授权展示已按上面的到期弹窗要求调整。

部署步骤见 [统计更新部署](统计更新部署.md)。
