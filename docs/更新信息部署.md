# 软件更新与公告部署

当前通过 `python main.py` 做源码测试，不生成客户端程序包或压缩包。只有明确要求发布时才打包。

## 首次部署到宝塔

如果服务器已经提供 `/videoDown.txt`，本次公告功能只需覆盖 `payment_server/app.py` 并重启项目一次，然后在**线上现有的** `videoDown.txt` 中追加可选的 `announcement` 字段。保留线上原有的版本号、下载链接、更新说明和强制升级设置；仓库中的示例文件不用于替换已有线上配置。不修改数据库、支付配置或套餐。

以下两文件部署步骤适用于尚未部署版本信息接口的服务器：

本次服务端只需上传以下两个文件：

| 本地项目文件 | 宝塔目标路径 |
| --- | --- |
| `服务端/payment_server/app.py` | `/www/wwwroot/douyinDown/payment_server/app.py` |
| `服务端/videoDown.txt` | `/www/wwwroot/douyinDown/videoDown.txt` |

部署以当前两表版本的支付服务为基础；若之前的用户统计更新尚未部署，先按统计更新说明完成升级。

1. 保存原 `app.py` 的副本，再上传上述两个文件。不覆盖 `.env`、`payment_server/config.py` 或数据库。
2. 重启宝塔 Python 项目一次，使新增接口生效。确保反向代理将 `/videoDown.txt` 转发到该 Python 项目，且该路径没有额外的代理缓存。
3. 访问 `https://douyindown.secs.cc/videoDown.txt`，应返回 JSON，其中包含原阿里云文件的五个字段。接口无需登录或设备令牌，响应含 `Cache-Control: no-store`。
4. 确认地址可用后，在本地使用当前源码运行 `python main.py`；也可使用项目虚拟环境的 Python 运行。

客户端更新地址为上述域名。数字日期版本在服务器版本号大于客户端时提示更新，非数字版本保留不相等时提示的兼容行为；更新请求失败仍按现有逻辑提示并退出。本次新增公告不更改现有版本号、版本判断或强制升级规则。

上传和重启由宝塔操作完成。使用当前域名的旧客户端会忽略新增公告字段；仍访问原阿里云地址的早期客户端不受本次接口扩展影响，过渡期间保留原文件。

## 日常修改更新信息

直接在宝塔编辑项目根目录的 `videoDown.txt`，保存为 UTF-8 JSON：

| 字段 | 含义 |
| --- | --- |
| `version_number` | 版本号字符串，对应客户端更新判断 |
| `百度` | 百度网盘下载链接字符串 |
| `夸克` | 夸克网盘下载链接字符串 |
| `info` | 更新说明字符串，换行使用 JSON 的 `\n` |
| `forced_upgrade` | 是否强制升级，推荐填写布尔值 `true` 或 `false`，仍兼容原字符串 `"False"`／`"True"` |
| `announcement` | 可选公告纯文本，换行使用 JSON 的 `\n`；留空、只有空白或缺失时不弹公告 |

服务端每次请求读取文件，修改并保存后即可生效，无需重启。接口只返回原五个字段和可选的公告文本，不开放整个项目目录。`.env` 继续保存商户密钥、试用天数等内部配置。

文件不存在、不是有效 UTF-8 JSON、缺少必要字段或字段格式错误时，接口返回 503 和明确错误说明，不返回虚构版本。检查 JSON 的引号、逗号及换行写法，修正并保存即可恢复。

## 公告填写和显示规则

在原 JSON 对象的最后一个字段后加逗号，再追加这一项；下面的内容仅是新增字段示例：

```json
"announcement": "软件公告第一行\n第二行内容"
```

关闭公告时将内容改为 `"announcement": ""`，也可以删除这一项。公告字符串支持中文和换行，客户端按纯文本显示；长内容可滚动查看。可选字段误填为数字、布尔值、数组、对象或 null 时会被忽略，不影响原五个字段的版本检查；整个文件仍须符合 JSON 语法。

每次启动只请求一次版本信息，同时获取公告；本次启动最多弹一次公告，不保存已读状态，下次启动相同公告仍会显示。

| 情况 | 弹窗顺序 |
| --- | --- |
| 无新版本、有公告 | 直接显示“软件公告” |
| 普通升级、有公告 | 升级提示关闭后，再显示公告；点击任一下载链接或“暂不升级”均遵循此顺序 |
| 强制升级 | 保持升级和退出流程，不显示公告 |
| 公告为空、缺失或类型错误 | 不显示公告，版本检查正常进行 |
| 版本请求失败 | 保留现有失败提示及退出流程 |

公告窗口标题为“软件公告”，按钮为“我知道了”，支持关闭。旧客户端忽略新增字段；新客户端连接旧服务端时，将缺失的公告视为空。日常修改公告不需要改变版本号；本次客户端发布版本为 `20261020`，线上发布版本号与下载地址在新包上传后再由维护者更新。

本地运行方式保持 `python main.py`。线上文件未填写公告或服务端尚未更新时，新客户端不会显示公告。可以在本机临时服务中填写内容验证，自动化测试使用临时文件和隔离的界面，不修改线上配置。
